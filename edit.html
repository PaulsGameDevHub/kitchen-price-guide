How to make a key (once, about two minutes)
  1. Open this GitHub page while signed in.
  2. Give it any name, e.g. price editor.
  3. Expiration — pick a date, or No expiration if you'd rather not redo this.
  4. Repository access → Only select repositories → choose kitchen-price-guide.
  5. Permissions → Repository permissions → find Contents → set to Read and write.
  6. Click Generate token, copy it, and paste it into the box above.

That key can only touch this one repo, nothing else on your account. If you ever lose the device, delete the key on GitHub and it stops working immediately.
